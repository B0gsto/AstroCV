# Bogdan Stoica — Personal Site

A fast Astro portfolio focused on my current Software Engineer profile: Azure, Next.js, React Native, integrations and AI workflow systems.

## Tech Stack

- Astro
- TypeScript
- MDX Content Collections
- Vanilla CSS design system

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

The generated static site is emitted to `dist/`.
